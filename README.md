# Cloud-Based Data Analytics Dashboard
Cloud-based real-time data analytics dashboard using AWS Kinesis, Lambda, Redshift, and web technologies.

## Project Overview

This project implements a cloud-based real-time data analytics dashboard using AWS services.

## AWS Services Used

- Amazon Kinesis – Real-time data ingestion
- AWS Lambda – Data processing
- Amazon Redshift – Data storage and analytics
- Web Dashboard – Data visualization

## Features

- Real-time data ingestion
- Serverless data processing
- Cloud-based data storage
- Data visualization dashboard
- Scalable cloud architecture

## Technologies

Python, AWS Kinesis, AWS Lambda, Amazon Redshift, HTML, CSS, JavaScript
